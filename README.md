## 📖 项目简介

    本项目旨在实现并拓展“基于深度学习的无人机航拍图像配准”任务，核心构建了选择性上下文网络（Selective Context Network With Neighborhood Consensus, SC-Net）[cite: 4]。由于无人机航拍图像通常在不同环境中获取且存在显著视角差异，同时包含大量如道路、建筑物或树林等重复图案，导致传统的特征提取与匹配极其困难[cite: 4]。

    为解决上述挑战，本项目采用以下核心技术架构实现图像的精准对齐：
*   **特征提取：** 采用 ResNet-101 作为骨干网络，以避免梯度消失或爆炸，从源图像和目标图像中提取共享权重的密集特征[cite: 4]。
*   **选择性信息融合：** 设计了一种基于注意力机制的选择性融合策略，通过全局平均池化与 SoftMax 机制，选择性地融合局部特征和嵌入的空间特征，避免模型陷入由重复纹理引起的局部最优[cite: 4]。
*   **轻量级邻域一致性：** 引入优化的轻量级邻域共识模块，结合非对称匹配的四维稀疏卷积张量与二维稠密卷积网络，以较低的时间复杂度实现精确的匹配过滤[cite: 4]，最终通过全连接层回归出图像对之间的 6 个仿射变换参数[cite: 4]。

    在此架构基础上，为进一步突破模型在面对无人机剧烈偏航（极端大尺度缩放与旋转）时的表征极限，本项目引入了**渐进式课程学习（Progressive Curriculum Learning）**与余弦退火训练策略。该方法成功引导网络跨越了高难度大形变下的梯度饥饿瓶颈，在大幅提升模型抗扭曲鲁棒性的同时，实现了卓越的配准精度。

## 项目局限性
    在面对大尺度缩放、平移、旋转时，容易出现特征坍塌。
    准确性仅局限于以下范围：
        # 旋转：[-60°, 60°]    
        # 缩放：[0.6, 1.5]    
        # 平移：[-40, 40]



## 🏆 核心评估战果

    本项目进行了两组严格的控制变量测试，以验证模型的精度与抗形变鲁棒性：

*  **基准降维测试 (Easy Mode):** 在传统微小形变基准（旋转 30°，缩放 0.8-1.2，平移 30 像素）下，本模型的 PCK (tau=0.1) 达到了 **83.37%**[cite: 4]。这一成绩在同等条件下显著超越了 SNCNET 基线成绩（79.2%）[cite: 5]。
*  **极限抗扭曲测试 (Medium-Hard Mode):** 在剧烈的大尺度形变（旋转 60°，缩放 0.6-1.5，平移 40 像素）下[cite: 4]，本模型依然保持了极高的结构感知力，PCK (tau=0.1) 达到 **65.79%**[cite: 4]，在真实航拍图推理中实现了视觉上的完美像素级重合.

## 🚀 运行指南
    本项目将训练、评估与推理流程进行了严格解耦。为了满足不同需求，提供以下两种运行方式：

方式一：快速测试与查看效果图 (推荐快速验证)
    如果您只想测试模型的实际抗形变配准能力，请直接使用预训练权重进行可视化推理。

1. 准备源图： 在项目根目录放入任意一张航拍图片，并将其重命名为 real_source.jpg。(SCNet_Demo_Weights.zip里有准备)

2. 生成目标图： 运行测试用例生成脚本（generate_test.py），程序会自动根据预设的高难度仿射变换参数，生成一张发生剧烈几何扭曲的目标图 real_target.jpg。

3. 执行推理出图： 确保预训练权重（随附压缩包中的 hard_mode_epoch_27.pth）已解压并放置在指定目录，运行可视化脚本：python test_real.py。
   运行结束后，根目录会自动生成 real_inference_result.png，同时终端日记中也会直观展示预测仿射参数。



方式二：从头开始训练与评估 (完整复现)
    如果您希望从零开始复现本项目的完整技术链路，请按以下步骤操作：

1. 数据预处理： 将原始航拍数据集放入 ./raw_data/ 目录，运行预处理脚本完成数据清洗与无污染划分：python prepare_data.py

2. 启动课程学习训练： 确保基础特征权重("./checkpoints_finetune/finetune_epoch_7.pth"，附于.zip压缩包里)已就位，运行核心训练脚本：python train_hard.py，

模型将开始应对中高难度的大尺度形变。训练产生的权重将实时保存在 ./checkpoints_hard_mode/ 目录下。

3. 多轮次交互式评估： 训练结束后（推荐训练30—50轮）运行评估脚本：python evaluate.py 。
终端会列出所有的权重文件供您交互式选择，并自动计算该权重在独立测试集上的最终 PCK 准确率。
